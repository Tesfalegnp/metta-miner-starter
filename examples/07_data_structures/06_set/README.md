Set
===

What is this?
- Unordered collection of unique items.

Why learn it?
- Useful for membership tests and visited sets in graph algorithms.

Python example: `set_demo.py` demonstrates membership and uniqueness.
MeTTa/MORK: facts like `(Member x S)` can represent set membership.
Set — Python vs Symbolic
=========================

This example demonstrates set operations in Python and explains how
symbolic facts can be treated as sets in MeTTa/MORK.

Run the Python demo:

```bash
python3 examples/07_data_structures/06_set/set_demo.py
```
