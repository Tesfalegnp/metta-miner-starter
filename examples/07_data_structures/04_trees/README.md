Trees
=====

What is this?
- Binary trees with node left/right children.

Why learn it?
- Tree traversals are fundamental: preorder, inorder, postorder.

Python example: `tree.py` prints traversal orders for a small tree.
MeTTa/MORK: represent parent/child with `(Left A B)` `(Right A C)` atoms; rules can compute traversals by recursion.
Trees — traversal and MeTTa notes
=================================

This folder demonstrates tree traversals (preorder/inorder/postorder)
in Python and in MeTTa (symbolic). Use the recursive MeTTa examples from
`05_recursion` as a reference.

Run the Python traversal:

```bash
python3 examples/07_data_structures/04_trees/tree_traversal.py
```

Run the MeTTa demo:

```bash
python3 examples/07_data_structures/04_trees/run_tree.py
```
