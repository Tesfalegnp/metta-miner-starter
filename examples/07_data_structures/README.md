07_data_structures — Data structures overview
=============================================

What is this?
- Introduces fundamental data structures: stack, queue, linked list, trees, hashmap, set.

Why learn it?
- These structures underpin algorithms in later modules (search, graphs, sorting).

Python example: each subfolder contains runnable Python demos.
MeTTa perspective: symbolic representations (atoms) represent structure membership and links.
MORK/MM2 perspective: facts and rules can represent relations like edges and parent links; rule-based derivation can compute closures but is not a procedural data structure.

Expected result: each demo prints deterministic outputs; tests verify those outputs.

What to understand: usage, operations, and traversal orders (trees: preorder, inorder, postorder).
07_data_structures — Data Structures (educational)
=================================================
