Linked List
===========

What is this?
- Singly linked list with nodes pointing to next.

Why learn it?
- Introduces node pointers and traversal patterns.

Python example: `linked_list.py` demonstrates append and traversal.
MeTTa/MORK: represent links with atoms like `(Next A B)`.
Linked List — Python and MeTTa
================================

This example demonstrates a simple singly linked list in Python and a
symbolic representation in MeTTa. Run the Python and MeTTa demos to see
how traversal and insertion differ in the two models.

```bash
python3 examples/07_data_structures/03_linked_list/linked_list.py
python3 examples/07_data_structures/03_linked_list/run_linked.py
```
