HashMap
=======

What is this?
- Key-value mapping; Python `dict` is a hashmap abstraction.

Why learn it?
- Constant-time average lookup for keyed data; used for adjacency lists and memoization.

Python example: `hashmap.py` demonstrates set/get.
MeTTa/MORK: use atoms to represent key-value facts `(KV key value)`.
Hash Map / Dictionary — Python vs Symbolic
=========================================

This example compares Python dictionaries with symbolic key/value facts.
In MeTTa and MORK we represent mappings as facts like `(KV key value)`.

Run the Python demo:

```bash
python3 examples/07_data_structures/05_hashmap/hashmap.py
```
