Queue
=====

What is this?
- FIFO structure. Use `enqueue` to add and `dequeue` to remove.

Why learn it?
- Queues power BFS, event loops, and producer/consumer patterns.

Python example: `queue.py` demonstrates enqueue/dequeue.
MeTTa/MORK: queues are procedural and not a natural fit; represent sequences as lists or atoms instead.
Queue — Python, MeTTa, MORK notes
================================

This simple example shows a queue implemented in Python and a symbolic
representation in MeTTa. MORK/MM2 analogies are described in the README.

Run the Python demo:

```bash
python3 examples/07_data_structures/02_queue/queue.py
```

Run the MeTTa demo:

```bash
python3 examples/07_data_structures/02_queue/run_queue.py
```
