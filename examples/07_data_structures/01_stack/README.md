Stack
=====

What is this?
- LIFO structure. Push and pop operations.

Why learn it?
- Underpins recursion and DFS implementations.

Python example: `stack.py` demonstrates push/pop/peek.
MeTTa/MORK: stacks are procedural; show list-like atoms for symbolic stacks when needed.
Stack — Python, MeTTa, MORK notes
================================

This example shows a simple stack implemented in Python and a symbolic
representation in MeTTa. MORK/MM2 is not a natural model for a mutable
stack, so we describe an analogous representation in the folder.

Run the Python example:

```bash
python3 examples/07_data_structures/01_stack/stack.py
```

Run the MeTTa demo:

```bash
python3 examples/07_data_structures/01_stack/run_stack.py
```
